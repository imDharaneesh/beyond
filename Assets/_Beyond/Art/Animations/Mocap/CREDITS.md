# Motion capture

Clips from the CMU Graphics Lab Motion Capture Database (http://mocap.cs.cmu.edu), BVH conversion from https://github.com/una-dinosauria/cmu-mocap.
The database is free to use; CMU asks for the acknowledgement: "The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217."
